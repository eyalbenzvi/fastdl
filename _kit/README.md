# חבילת בנייה: אב-טיפוס "רישיון עד הבית" (fastdl.co.il)

חבילה מלאה לבניית אב-טיפוס HTML לחיץ ורספונסיבי באמצעות **Claude Code**.
העיצוב כבר קיים ואושר כבסיס בקנבס של Claude Design. התפקיד של Claude Code הוא לבנות אותו כאתר סטטי עובד, נקי ומתוחזק, 1:1 מול ההדמיות.

---

## איך מתחילים (5 דקות)

1. **פתחו את הזיפ** לתיקייה חדשה, למשל `fastdl-prototype/`.
2. **פתחו טרמינל בתיקייה** והריצו `claude`.
3. **הדביקו את פרומפט הפתיחה** מתוך `START_HERE_PROMPTS.md` (פרומפט 0).
4. Claude Code יקרא את `CLAUDE.md` אוטומטית. הקובץ מכיל את כל הכללים, הסדר והגדרת "גמור".
5. **אחרי כל אבן דרך**, השתמשו בפרומפט ההמשך המתאים מ-`START_HERE_PROMPTS.md`, ובדקו את התוצאה מול `mockups/index.html`.

> טיפ: פתחו את `mockups/index.html` בדפדפן. זו גלריה של כל 67 המסכים והמצבים, בדסקטופ ובמובייל, עם קישור ל-HTML הסטטי של כל אחד.

## החלטות שכבר התקבלו (ואפשר לשנות)

- **סטאק:** HTML/CSS/JS סטטי, בלי build ובלי framework, ריבוי עמודים, כפי שהוגדר ב-Brief (סעיף 14). קל להעלות לכל אחסון ולהציג ללקוח. רוצים React/Next? עדכנו את `CLAUDE.md` לפני שמתחילים.
- **עמוד הבית:** שתי הגרסאות נבנות (A ו-B). גרסה B היא דף הבית המומלץ ונבנית כ-`index.html`; גרסה A נבנית כ-`home-a.html`. אינדקס האב-טיפוס יושב ב-`prototype-index.html`.
- **תמונת ה-Hero:** הוחלפה באיור וקטורי כללי (`design/brand/license-card-illustration.svg`). התמונה המקורית ברזולוציה נמוכה ונראית כמו מסמך ממלכתי אמיתי.
- **לוגו משרד התחבורה:** מופיע רק כ-placeholder מקווקו. אין להשתמש ב-`assets/logos/mot_logo_ref.png`.

## לפני שמשתמשים בתוצר מחוץ לארגון

- כל ערך **[לאישור]** (רשימה מלאה ב-`docs/10_open_items.md`) צריך מקור מאושר.
- נוסחים משפטיים (תנאי שימוש, הסכמה ל-SMS, הנפקה חוזרת) – לבדיקה משפטית.
- הוורדמרק הוא בנייה ב-HTML; לוגו דפוס בארי הרשמי צריך להגיע כקובץ וקטורי.
- התרגום לערבית הוא טיוטה, לבדיקת מתרגם.
