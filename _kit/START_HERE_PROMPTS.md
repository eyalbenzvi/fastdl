# פרומפטים ל-Claude Code

העתיקו את החבילה לתיקייה, הריצו בה `claude` והדביקו את פרומפט 0. אחרי כל אבן דרך, בדקו את התוצאה (גלריה: `mockups/index.html`) ורק אז הדביקו את הפרומפט הבא.

---

## פרומפט 0 – פתיחה (הדבק כמו שהוא)

```
אתה בונה אב-טיפוס HTML לחיץ ורספונסיבי לאתר "רישיון עד הבית" (fastdl.co.il) של דפוס בארי, בעברית RTL.

לפני שאתה כותב שורת קוד:
1. קרא את CLAUDE.md במלואו.
2. קרא את docs/01 עד docs/11 לפי הסדר.
3. פתח את mockups/manifest.json ועבור על רשימת המסכים והמצבים.
4. כתוב לי בקצרה (עד 15 שורות): מה הבנת, איך תבנה את מבנה הקבצים, ואילו שאלות פתוחות יש לך. אל תשאל על דברים שכבר מוגדרים במסמכים.

אחרי שאאשר, התחל באבן דרך 1 מתוך docs/11_milestones.md. בסוף כל אבן דרך: הרץ את הבדיקות שלה, צלם מסכים ב-1280 וב-390, השווה להדמיות ב-mockups/, תקן פערים, ודווח מה נבנה ומה פתוח. אל תעבור לאבן הדרך הבאה בלי אישור שלי.
```

## פרומפט להמשך (אחרי כל אבן דרך)

```
מאושר. המשך לאבן דרך [N] ב-docs/11_milestones.md. אותם כללים: בנה, בדוק מול ההדמיות ב-1280 וב-390, תקן, ודווח.
```

## פרומפט לבנייה רציפה (אם לא רוצים לעצור בין אבני דרך)

```
בנה את כל אבני הדרך ב-docs/11_milestones.md ברצף, בלי לעצור לאישור. בסוף כל אבן דרך עדיין הרץ את הבדיקות וההשוואה הוויזואלית ותקן פערים לפני שאתה ממשיך. בסוף, תן לי דוח אחד: מה נבנה, תוצאות הבדיקות, החלטות שקיבלת (DECISIONS.md) ומה נשאר פתוח.
```

## פרומפטים לתיקונים ובקרה

- **סבב השוואה ויזואלית:**
  ```
  צלם את כל המסכים לפי mockups/manifest.json (כולל כל המצבים, עם פרמטרי ה-URL מ-docs/02_architecture.md §4) ב-1280 וב-390. לכל מסך, השווה לתמונה באותו id ב-mockups/ ותן רשימת פערים לפי חומרה. אחר כך תקן את כולם.
  ```
- **בדיקת קריטריוני קבלה:**
  ```
  עבור על docs/09_qa_acceptance.md סעיף אחר סעיף. לכל סעיף: עובר/נכשל + הוכחה (קובץ, שורה או צילום). תקן כל מה שנכשל ותן לי את הרשימה המעודכנת.
  ```
- **בדיקת נגישות:**
  ```
  הרץ axe-core (דרך Playwright) על כל העמודים, ובדוק ניווט מקלדת מלא בתהליך ההזמנה ובמגירות. תקן כל הפרה ברמה serious ומעלה.
  ```
- **עדכון ערכים שאושרו:**
  ```

- **פריסה לבדיקה:**

  ```
