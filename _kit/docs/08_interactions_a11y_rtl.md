# 08 – אינטראקציה, נגישות ו-RTL

## 8.1 תנועה
- מעברים 150–200ms בלבד (fade/slide), `cubic-bezier(.2,.7,.2,1)`.
- `prefers-reduced-motion: reduce` מבטל הכול: פעימה בציר, ספינרים (נשאר אייקון סטטי), שלד, מגירות.
- בלי אנימציות דקורטיביות ובלי parallax.

## 8.2 מגירות ומודאלים – התנהגות מחייבת
1. פתיחה: `scrim` + פאנל, `document.body.style.overflow='hidden'`, שמירת `document.activeElement`.
2. פוקוס: לכותרת הפאנל (`tabindex="-1"`) או לכפתור הסגירה.
3. Focus trap: Tab/Shift+Tab מסתובבים בתוך הפאנל.
4. סגירה: כפתור ✕, Esc, לחיצה על ה-scrim, וכפתור הפעולה התחתון.
5. בסגירה: הפוקוס חוזר לכפתור שפתח, והגלילה משתחררת.
6. `role="dialog"` + `aria-modal="true"` + `aria-labelledby`. התוכן שמאחורי הפאנל מקבל `inert` (או `aria-hidden="true"`).
7. דסקטופ: מגירת מידע משמאל, תפריט מימין, מודאל במרכז. מובייל (≤640): שלושתם bottom-sheet.

## 8.3 ולידציה

### תעודת זהות (`Validate.israeliId`)
```js
function israeliId(input) {
  let v = String(input || '').replace(/\D/g, '');
  if (!v || v.length > 9) return false;
  v = v.padStart(9, '0');                 // משלימים אפסים משמאל
  let sum = 0;
  for (let i = 0; i < 9; i++) {
    let d = Number(v[i]) * ((i % 2) + 1);  // משקלות 1,2,1,2…
    sum += d > 9 ? d - 9 : d;
  }
  return sum % 10 === 0;                   // 000000018 → true
}
```
### נייד (`Validate.mobile`)
`/^05\d{8}$/` אחרי הסרת כל מה שאינו ספרה. מותר להקליד עם מקפים. **מיסוך:** `054-•••-4567` (3 ראשונות, 3 נקודות, 4 אחרונות).

### מתי מציגים שגיאה
- ב-submit (לא בזמן ההקלדה). שדה שכבר סומן כשגוי מתנקה ברגע שמתחילים לתקן אותו.
- שגיאה: `aria-invalid="true"`, הודעה `role="alert"` עם אייקון alert-circle, מקושרת ב-`aria-describedby`, ופוקוס לשדה השגוי הראשון.
- הקלט מסונן: בשדה ת״ז רק ספרות (עד 9); בנייד ספרות ומקף (עד 11).

| מקום | משך | טקסט |

| תשלום (P08) | 1.4 שניות | מעבדים את התשלום… |

כפתור בטעינה: `aria-disabled="true"` + `aria-busy="true"` + ספינר (לא `disabled` – כפתור מושבת שמחזיק את הפוקוס מפיל אותו ל-BODY; לחיצה ו-submit נבלעים ב-JS, `UI.setBusy`, החלטה P3-4). רוחב הכפתור לא קופץ (min-width).

## 8.5 נגישות – רשימת בדיקה
- [ ] `<html lang="he" dir="rtl">` (בערבית `lang="ar"`); `<title>` ייחודי לכל עמוד.
- [ ] קישור "דלג לתוכן הראשי" ראשון ב-Tab, מוביל ל-`<main id="main" tabindex="-1">`.
- [ ] Landmarks: `header`, `nav` עם aria-label, `main`, `footer`; `role="search"` ב-FAQ.
- [ ] היררכיית כותרות תקינה: H1 אחד לעמוד, בלי דילוגים.
- [ ] ניגודיות: טקסט ≥4.5:1, טקסט גדול ורכיבי ממשק ≥3:1. (הטוקנים כבר עומדים בזה; אל תמציא צבעים.)
- [ ] `:focus-visible` – טבעת 3px #FFB020, offset 2px, בכל אלמנט אינטראקטיבי (כולל radio cards דרך `:focus-within`).
- [ ] יעד לחיצה ≥44×44 (כפתורי אייקון, צ'יפים, קישורי חזרה).
- [ ] כל אייקון דקורטיבי `aria-hidden="true"`; כפתור אייקון עם `aria-label`.
- [ ] טפסים: `<label for>`, `aria-describedby` לעזרה ולשגיאה, `aria-invalid`, `role="alert"`; `inputmode` ו-`autocomplete` מתאימים.
- [ ] קבוצות רדיו: `role="radiogroup"` + `aria-label` (או fieldset/legend).
- [ ] צ'יפים ובוררי מצב: `aria-pressed`. אקורדיון ו"עוד": `aria-expanded` + `aria-controls`.
- [ ] ציר: `<ol>` + `aria-current="step"` + טקסט נסתר (הושלם/נוכחי). Stepper מובייל: `role="progressbar"` עם ערכים.
- [ ] סטטוס לא מועבר בצבע בלבד: תמיד אייקון + מילה.
- [ ] תוכן שמשתנה דינמית (תשובות S0, חשיפה ב-S7, תוצאת מחשבון, מונה FAQ, מונה תווים): `aria-live="polite"`.
- [ ] קישור חיצוני: אייקון + "(נפתח בלשונית חדשה)" נסתר.
- [ ] הגדלת טקסט ל-200% וזום 400% (reflow ב-320px) בלי גלילה אופקית ובלי חיתוך.
- [ ] כל העמודים עוברים axe-core בלי הפרות serious/critical.
- [ ] כפתור "נגישות" ב-Header – placeholder (לא תוסף צד-שלישי).

## 8.6 RTL – כללים
- **Logical properties בלבד:** `margin-inline-start/end`, `padding-inline`, `inset-inline-start`, `text-align: start`. אסור `left/right` בפריסה – חריגים מתועדים: מיקום מגירת מידע (left) ותפריט (right), כפתור "?" בכרטיס, demo-pill.
- **חיצים:** "קדימה/המשך/לפרטים" = `chevron-forward-rtl` (‹, מצביע שמאלה). "חזרה" = `chevron-back-rtl` (›, מצביע ימינה). החץ בטקסט "←" (כמו "צריכים את הרישיון בדחיפות? ←") מצביע שמאלה = קדימה.
- **סדר ויזואלי:** בכל row – מימין לשמאל: אייקון/טקסט ← פעולה. הציר וה-Stepper מתחילים מימין.
- **מספרים ו-LTR:** ת״ז, טלפונים, תאריכים, שעות, מספרי הזמנה/מעקב/פנייה, סכומים, `fastdl.co.il`, `*5678` → `<span class="num" dir="ltr">`. ב-`*5678` להוסיף LRM (‎) לפני הכוכבית. שדות קלט מספריים: `dir="ltr"` + `text-align: right`.
- **סימן ₪:** אחרי המספר ("177 ₪"), חוץ מכפתור התשלום ("תשלום ₪177 וסיום") – כמו בהדמיה.
- **גרשיים:** ת״ז, נתב״ג, א׳–ה׳, לו״ז – עם התווים ״ (U+05F4) ו-׳ (U+05F3), לא " ו-'.
- **Play בסרטון:** לא מתהפך.
- בדוק כל עמוד גם עם `dir="rtl"` וגם בערבית.
