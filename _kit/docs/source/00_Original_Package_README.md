## איך מתחילים
1. לקרוא את `01_UX_Review` ולהכריע בטבלת ההחלטות שבסופו (בעיקר: גרסת עמוד הבית, OTP, שם השירות).
2. לעדכן ב-`02_Claude_Design_Brief.md` ו-`05_mock-data.json` את הערכים המסומנים **[לאישור]** שכבר ידועים לכם.
3. להעלות את החבילה ל-Claude Design ולהדביק את הפרומפט מקובץ 03.

## לפני שמשתמשים בתוצר מחוץ לארגון
- לוגו משרד התחבורה – רק באישור כתוב.
- הלוגואים כאן הם חיתוכי רסטר; להחליף בקבצים וקטוריים רשמיים.
- כל נוסח משפטי (הסכמה ל-SMS, תנאי שימוש, הנפקה חוזרת) – לבדיקה משפטית, כפי שמצוין גם במצגת.
